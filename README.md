## Portfolio Summary

- Mobile-first client in Expo + React Native
- Node.js + Express backend
- MongoDB
- Authentication with JWT and Passport
- Cache with Redis
- Realtime messages in DM and group chats (channels) with Socket.IO
- Media upload with storage in Cloudinary
- Multi-screen navigation for communities, chats, profiles and subtabs
- Role-based community management features
- Community feeds with posts, galleries, and events
